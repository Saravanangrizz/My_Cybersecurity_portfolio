# Cybersecurity Portfolio - C. Saravanan

Welcome to my personal cybersecurity-themed portfolio built using **React**!  
This site highlights my passion for ethical hacking, security projects, certifications, and experience in cybersecurity.

## 🚀 Features

- Dark-themed UI for a sleek hacker aesthetic
- Project highlights including log analysis and password security
- Certifications and virtual internships
- Contact section with links to GitHub and LinkedIn

## 🛠️ Technologies Used

- React.js
- CSS (Dark Theme)
- Git + GitHub
- Render (Deployment)
